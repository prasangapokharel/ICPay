## How the SNS dashboard page works

The page `dashboard.internetcomputer.org/sns/<root-canister-id>` is a **Next.js server-rendered app**. The client bundle contains **zero API calls** — all data is fetched server-side and shipped to the browser as one JSON blob under `__NEXT_DATA__.props.pageProps.serverSideData.apiData` (51 aggregated fields). So there is no single "dashboard API" you can hit directly; the dashboard's server fans out internally. But the pieces it aggregates map to **public endpoints** you *can* call directly. Here they are, with live response examples.
